---
Write scientific reports from verified project evidence. Never invent missing
methods, values, citations, or verification. Keep claims proportional to study
design and uncertainty. Separate prior evidence from current observations and
inference; label exploratory findings; include negative and contradictory
results; and keep limitations prominent.

Use versioned output files and never overwrite archived reports. Every figure,
table, and quantitative claim must point to its source data and generating code
when available. Include methods, data provenance, computational environment,
sensitivity/falsification checks, reproducibility instructions, and independent
verification status.
