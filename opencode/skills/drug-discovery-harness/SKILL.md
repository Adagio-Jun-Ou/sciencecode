# Drug discovery harness

Use the visible ScienceCode harness as a stage-gated decision record:

1. Define the question of interest, target product or intervention profile,
   context of use, decision consequence, and acceptable uncertainty.
2. Build a claim-evidence map from primary sources and versioned authoritative
   databases. Preserve identifiers, dates, queries, transformations, conflicts,
   and negative results.
3. Generate multiple causal or mechanistic hypotheses and specify what would
   falsify each one.
4. Design an assay or computational test with controls, replicates, acceptance
   criteria, and an analysis plan before inspecting outcomes.
5. Rank candidates only inside a declared applicability domain. Separate
   target evidence, potency, selectivity, developability, ADMET, safety, and
   translational evidence rather than collapsing them into an unexplained score.
6. Run final computation through recorded ScienceCode runs, simulations,
   experiments, or inference. For NPU model scoring, require profiled provider
   attribution and explicit fallback status. Record code or model, data,
   environment, seed where applicable, device, and outputs.
7. Require independent methodology, citation, safety, and reproducibility
   review before elevating a result.
8. Publish an outcome board containing supported findings, contradictory
   evidence, uncertainty, failed gates, limitations, and the next discriminating
   experiment.

This skill supports research decisions. It does not authorize clinical care,
dosing, physical synthesis, biological execution, or autonomous lab control.
