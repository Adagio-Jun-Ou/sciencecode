# Model credibility

For every consequential model output:

1. Define the question of interest and exact context of use.
2. Assess model influence and the consequence of a wrong decision.
3. State the applicability domain, data provenance, exclusions, leakage risks,
   uncertainty, and known failure modes.
4. Predefine performance and acceptance criteria appropriate to the risk.
5. Verify code and calculations; validate against fit-for-use independent data.
6. Record deviations and determine whether evidence is adequate for the stated
   context, inadequate, or requires a narrower context.
7. Define monitoring, change control, and re-evaluation needs.

Do not reuse a credible output outside its validated context without a new
assessment.
