# Literature review protocol

Define inclusion/exclusion criteria and date scope. Search with multiple query formulations. Prefer primary papers, systematic reviews for orientation, official standards, and original datasets. Capture DOI/identifier when available. For each pivotal source record study type, sample/population, intervention/exposure, outcome, effect direction/magnitude, uncertainty, limitations, and conflicts of interest if reported. Explicitly include high-quality negative or contradictory evidence.
