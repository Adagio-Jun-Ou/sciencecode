# Scientific data-analysis protocol

Inspect dimensions, types, ranges, units, duplicate identifiers, missingness and outliers before modeling. Preserve raw data. Make transformations explicit. Choose statistical tests/models based on design and assumptions, not desired significance. Report effect sizes and uncertainty, not p-values alone. Check sensitivity to reasonable alternative specifications. Prevent train/test leakage and distinguish validation from test sets. Make figures traceable to code and data.
