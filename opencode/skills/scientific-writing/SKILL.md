# Scientific-writing protocol

Write from the evidence ledger, analysis outputs, and verified sources rather
than memory. Never fill a missing method, number, citation, or verification
result with a plausible invention.

Separate background evidence, current observations, computations, inference,
and recommendations. Match causal language to design. Report effect sizes,
units, uncertainty, negative findings, deviations, sensitivity analyses, and
limitations. Label exploratory analyses and post hoc hypotheses.

Make every table and figure traceable to data and code. Include data provenance,
software/environment, parameters/seeds, reproduction commands, and independent
verification status. Save a new versioned artifact; preserve earlier drafts.
